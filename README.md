# Game Theory & Board State Evaluation Analysis

An open technical publication exploring state evaluation algorithms, heuristic design, Expectiminimax, and neural network value functions in classical board games.

## Topics Covered
- Combinatorial State Spaces in American Checkers, Chess, and Backgammon
- Handcrafted Feature Vectors & Alpha-Beta Pruning
- Stochastic Search and Expectiminimax Chance Nodes
- Temporal Difference Learning & TD-Gammon
- Efficiently Updatable Neural Networks (NNUE)

Read the full analysis live on GitHub Pages:
